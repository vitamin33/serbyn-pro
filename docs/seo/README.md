# SEO and indexing notes

Status as of 2026-10-25: Google knows 1 page of the 26 in the sitemap, and Bing knows 0. No sitemap had been submitted to either. Fixing that is a manual step in the two consoles below.

## Submit the sitemap

Google Search Console

1. Open the property for https://serbyn.io (verified by `public/google79e0ddd11f99193e.html`).
2. Sitemaps, enter `sitemap.xml`, Submit.
3. Use URL Inspection on the home page, /audit and a few posts, then Request Indexing.

Bing Webmaster Tools

1. Sign in at bing.com/webmasters.
2. Choose "Import from GSC" so the site and its sitemap come across with the Google verification.
3. Check that https://serbyn.io/sitemap.xml is listed under Sitemaps. If not, submit it.
4. Under IndexNow, confirm the key is found at https://serbyn.io/9b2cc94f75734fdbad0f12e7cd94d7bd.txt.

## IndexNow

IndexNow tells Bing, Yandex, Naver and Seznam that URLs changed. Bing's index feeds ChatGPT search and Copilot. Google does not use it.

- Key file: `public/9b2cc94f75734fdbad0f12e7cd94d7bd.txt`. The key is public by design.
- Script: `scripts/indexnow.mjs`. No dependencies. It reads the sitemap and POSTs `{host, key, keyLocation, urlList}` to https://api.indexnow.org/indexnow.
- `npm run indexnow` submits the live sitemap URLs by hand.
- `node scripts/indexnow.mjs --dry-run` prints the payload and sends nothing.
- `postbuild` in package.json runs the script with `--if-production`. It submits only when `VERCEL_ENV === 'production'`, using the sitemap this build produced. Any other environment prints why it skipped. A failed ping never fails the build.

## Other files

## Traffic package (2026-11-11)

Baseline from PostHog, 23 Jun to 10 Nov: 135 pageviews in 84 sessions on serbyn.io. About 24 sessions were the owner and about 29 looked automated, so roughly 31 sessions were outside readers. Sources: direct 66, LinkedIn 11, Google 7, Bing 1.

What changed in the code:

- `robots.txt` no longer disallows `/_next/`. That folder holds the CSS and JS, and Google needs them to render a page.
- `/blog/the-calibration-ledger-58-runs-93-percent-pass-n-is-small` redirects to the real slug. A shared link with that slug was landing on the 404 page.
- A page title longer than 70 characters with the full site name gets the short suffix `| Vitalii Serbyn`.
- The browser sends analytics to `/ingest` on this site, and `next.config.js` forwards it to PostHog. Ad blockers no longer drop those events.
- Analytics run on `serbyn.io` only. Localhost, the Playwright build, `*.vercel.app` and automated browsers send nothing.
- Open any page with `?analytics=off` to stop counting your own browser. `?analytics=on` turns it back on.
- `/newsletter` records a `newsletter_click` event in PostHog from the middleware, with the lane (`featured` or `comment`).
- `scripts/github-links.sh` points the GitHub profile and the public repos at the site. It changes public GitHub metadata, so run it by hand.

Tests: `tests/refactor/traffic.spec.ts`.

Numbers before and after this date are not comparable: the proxy adds readers that ad blockers used to hide, and the filters remove the owner and local runs.
